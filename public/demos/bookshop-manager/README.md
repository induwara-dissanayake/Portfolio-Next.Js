# Bookshop Management System - Portfolio Static Demo 📚

A lightweight, standalone static demo website built with **HTML5, Tailwind CSS, and Vanilla JavaScript**.

This static demo showcases the UI/UX design, interactive features, navigation, and workflows of the **Bookshop Management System** without requiring any database, server, or backend setup. Perfect for hosting on GitHub Pages, Vercel, Netlify, or attaching to your developer portfolio!

---

## 🚀 Live Demo & How to Run

### Option 1: Open Locally in Browser (Zero Setup)
Simply open `index.html` directly in any web browser (Chrome, Firefox, Edge, Safari):
- Double click `index.html` or drag and drop it into your web browser.

### Option 2: Deploy to GitHub Pages
1. Push your repository to GitHub.
2. In your repo settings, navigate to **Pages**.
3. Select the `demo` folder (or root directory if moved) as the source branch.
4. Access your live portfolio link immediately!

---

## ✨ Features Included

- 📊 **Dashboard Overview**: Summary stats for Orders, Catalog, Customers, Revenue, and quick navigation cards.
- 📦 **Orders Management**: Order list with status filters (Pending/Completed), return date filter, interactive "New Order" builder modal with live price calculation, and order details drawer.
- 📖 **Book Catalog Management**: Full inventory view with search, add/edit book modal, stock level indicators, and deletion.
- 👥 **Customer Management**: Member directory with registration details, contact numbers, and search.
- ✍️ **Author Management**: Author list linked with book titles count and CRUD operations.
- 💳 **Loan Management**: Pending customer loans and settlement actions.
- 💰 **Finance Dashboard**: Daily & Monthly revenue view, average revenue per order calculation, and financial breakdown tables.
- 📈 **Reports & Export**: Built-in CSV report generator that generates and downloads instant reports directly in the browser!
- 💾 **Local Storage Persistence**: Any edits, new orders, or added books persist in your browser session via `localStorage` with a 1-click **Reset Demo Data** option.
